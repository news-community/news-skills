# Code of Conduct

## Our pledge

We want taking part in News Skills to be a welcoming experience for everyone, whatever their
background or identity. That includes the people this project exists for: community
journalists, bloggers, civic writers and researchers, many of whom are not programmers.

## Our standards

**Behaviour that helps:**

- Using welcoming and inclusive language
- Respecting differing viewpoints and experiences
- Giving and accepting constructive criticism with good grace
- Assuming good faith, and asking before concluding otherwise
- Focusing on what is best for the people who use the tool

**Behaviour that is not acceptable:**

- Trolling, insults, or derogatory comments
- Harassment, in public or in private
- Publishing someone else's private information without their permission, including an API key
  you found in an issue or a log
- Any conduct that would reasonably be considered inappropriate in a professional setting

## A note on the reporting this tool reads

This project is a client for newsrooms' published reporting. Disagreeing with a story is fine,
and the right place for a correction is the newsroom that published it, not this repository.
Using issues or pull requests to attack a reporter, a source, or a person named in coverage is
covered by this code like any other harassment.

## Enforcement

The maintainers are responsible for clarifying what is acceptable and will take fair corrective
action in response to behaviour that is not, which may include removing comments, commits or
issues, or blocking a participant.

Report a concern privately to **hello@communities.news**, or to a maintainer directly. Reports are
handled confidentially. If the concern is a security problem rather than conduct, see
[SECURITY.md](SECURITY.md) instead.

## Scope

This code applies in every project space: issues, pull requests, discussions, reviews, and any
other channel associated with the project, and when someone represents the project elsewhere.
